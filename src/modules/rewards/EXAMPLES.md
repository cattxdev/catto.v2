## Reward Stacking Examples

### Multiplicative Stacking
```
Base XP: 20 per message

Level 20: +10% → 22 XP per message
Level 40: +15% → 25.3 XP per message (1.1 × 1.15)
Level 60: +25% → 31.625 XP per message (1.1 × 1.15 × 1.25)
Level 80: +50% → 47.4375 XP per message (1.1 × 1.15 × 1.25 × 1.5)
```

### Role Replacement
```
Level 10: Bronze (Remove: None)
Level 25: Silver (Remove: Bronze)
Level 50: Gold (Remove: Silver)
Level 75: Platinum (Remove: Gold)
Level 100: Diamond (Remove: Platinum)
```

### Progressive Access
```
Level 10: Channel Group A (3 channels)
Level 25: Channel Group B (5 channels) + keep A
Level 50: Channel Group C (10 channels) + keep A, B
Level 75: All channels
```

## Reward Timing Strategies

### Early Game (Levels 1-20)
- Frequent small rewards (every 5 levels)
- Build excitement and engagement
- Teach system mechanics

### Mid Game (Levels 21-50)
- Moderate frequency (every 10 levels)
- More valuable rewards
- Maintain interest

### End Game (Levels 51-100)
- Rare but prestigious rewards (every 25 levels)
- Exclusive perks
- Status symbols

### Prestige (Levels 100+)
- Ultra-rare cosmetics
- Server recognition
- Unique privileges

## Multi-Track System

Some servers might want to track multiple XP types with unique rewards:

```
Text XP:    Social/Discussion rewards
Voice XP:   Communication rewards  
Event XP:   Participation rewards (future feature)
Gaming XP:  Game-specific rewards (future feature)
```

Each track has independent level progression and rewards!
